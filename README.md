## ⚡ About RedLine

**RedLine** (`redxline`) is a lightning-fast, minimalist web application built for Formula 1 fans who want instant insights without wading through heavy media bloat, ads, or cluttered dashboards. Whether you are tracking race weekend countdowns or checking live driver standings mid-grand prix, RedLine cuts straight to the chase.

---

## 🚀 Key Features

* **⏱️ Session Countdowns:** Precision timers tracking down to the exact second for upcoming Practice, Qualifying, Sprint, and Grand Prix sessions.
* **📊 Live Driver & Constructor Standings:** Real-time points tracking across the championship calendar.
* **📰 Paddock TL;DR:** Curated, bite-sized summaries of breaking news, technical upgrades, and race telemetry straight from the pit lane.
* **🌙 Cyberpunk Minimalist UI:** Designed with high-contrast, clean typography optimized for speed and readability.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Zero heavy framework bloat)
* **Hosting:** Hosted natively and globally via **GitHub Pages**
* **Data Layer:** Lightweight API integrations for real-time F1 data telemetry
